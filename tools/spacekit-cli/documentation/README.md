# SpaceKit CLI documentation

The authoritative command surface is [`../COMMANDS.md`](../COMMANDS.md).
Profile-driven network setup is documented in
[`../../../docs/guides/developer-network-setup.md`](../../../docs/guides/developer-network-setup.md).

Documents in `archive/` are historical implementation and session reports.
They contain old SWTCH naming, simulator-first workflows, obsolete DID formats,
and ports that must not be used as current guidance.

The former quick-start and node-discovery guides were retired because they
described compute on `:8080` and simulator orchestration as canonical. Use the
network guide and `spacekit <command> --help` instead.

Topic guides remaining in this directory must be checked against
`COMMANDS.md` and executable help before publication.
