# Spacetime documentation drafts

> Unreviewed work in progress — not production or operator guidance.

These drafts may describe commands, moderation behavior, classifiers, prompts,
or deployment states that are not exposed by the current CLI or implemented by
the current consensus crates.

Before promoting a document:

1. verify commands against `spacekit --help`;
2. verify protocol behavior against the consensus and contract code;
3. move reusable prompt material beside its owning agent;
4. move operator procedures into `operations/spacekit-runbook`;
5. replace status claims with reproducible test evidence.
